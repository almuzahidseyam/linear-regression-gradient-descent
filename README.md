# Linear Regression using Gradient Descent

A simple implementation of Linear Regression from scratch using NumPy.

## Features
- Linear regression with gradient descent
- Feature scaling
- Cost tracking during training
- House price prediction

## Dataset
Floor area (sqft) is used to predict house prices in lakh BDT.

## Requirements
- Python 3
- NumPy

## Run
python linear_regression_gradient_descent.py
